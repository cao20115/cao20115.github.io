# 2025年如何访问Wikipedia而不使用代理
## 浏览器访问
与 <a href="./001.html" id="001" style="color:#000000">2025年如何快速访问Github</a> 同理，在Chromium内核浏览器快捷方式地址栏加入如下参数：
```
--host-rules="MAP *wikipedia.org CYFM0,MAP  CYFM0,MAP  CYFM0," --host-resolver-rules="MAP CYFM0 185.15.59.224," --test-type --ignore-certificate-errors 

```

将 *wikidata.org、*wikimedia.org 映射到其他域名，以绕过SNI阻断

或使用如下脚本：

```cmd
@taskkill /im msedge.exe /f

@"C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --host-rules="MAP *wikipedia.org CYFM0,MAP *wikimedia.org CYFM0,MAP *wikidata.org CYFM0," --host-resolver-rules="MAP CYFM0 185.15.59.224," --test-type --ignore-certificate-errors "https://zh.wikipedia.org/"

@taskkill /im msedge.exe /f
```
